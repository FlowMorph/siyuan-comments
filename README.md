# 评论

给思源笔记加上可以跟帖的评论：在文字、块或整篇文档上开一个讨论串，可以回复、编辑、删除，标记已解决或重新打开。评论显示在右侧侧栏的「评论」面板里；窗口变窄时侧栏按思源原生方式收起，鼠标移到右边缘浮出。

## 使用

- 划词评论：选中文字，点浮动工具栏里的评论按钮，或按 `⌥⇧M`（可在设置 → 快捷键里修改）。
- 块评论：点块标 → 「评论」。
- 文档评论：点文档标题图标 → 「评论此文档」，或面板右上角的 `+`。
- 在面板里回复用 `⌘Enter` 发送；新建的讨论串按 `Esc` 或「取消」撤销。
- 点面板里的讨论串定位到正文；点正文里的高亮打开对应讨论串。

## 数据

讨论串以 JSON 存在块属性 `custom-comments` 里，划词评论的正文标记是带 `custom-comment-id` 属性的原生下划线。卸载插件后正文只剩普通下划线，评论数据仍保留在块属性中。
